The curriculum

Eight modules that take you from "what is an agent?" to training agentic models with reinforcement learning.

🧭Module 1

Foundations

What agents are, where they came from, the LLM engine inside them, and the loop that makes them act.

  1. What Is an AI Agent?
  2. A Brief History of AI Agents
  3. LLMs: The Engine Inside Every Agent
  4. The Agent Loop
  5. Agents vs. Workflows: When (Not) to Build an Agent
🧱Module 2

Core Building Blocks

Prompts, tools, reasoning, memory, retrieval and context — the components every agent is assembled from.

  1. Prompt Engineering for Agents
  2. Tool Use & Function Calling
  3. Designing Great Tools (The Agent–Computer Interface)
  4. Structured Outputs & Control Flow
  5. Reasoning & Planning
  6. Memory Systems
  7. Retrieval & Agentic RAG
  8. Context Engineering
🏗️Module 3

Architectures & Patterns

Proven workflow patterns, single- and multi-agent architectures, human oversight, and the protocols that connect agents to the world.

  1. Workflow Patterns
  2. Single-Agent Architectures
  3. Multi-Agent Systems
  4. Human-in-the-Loop & Agent UX
  5. Protocols: MCP, A2A & Interoperability
🌍Module 4

Agents in the Wild

How real agent categories work: coding agents, computer-use agents, deep research agents, conversational and voice agents.

  1. Coding Agents
  2. Computer-Use & Browser Agents
  3. Deep Research Agents
  4. Customer-Facing & Voice Agents
  5. The Agent Landscape: Use Cases by Domain

Building Agents

Write an agent from scratch, then learn the frameworks and SDKs that professionals use.

  1. Build an Agent From Scratch
  2. Frameworks & SDKs Compared
  3. Hands-On with Agent SDKs
🚀Module 6

Production Engineering

Evaluate, observe, harden, optimize and operate agents in the real world.

  1. Evaluating Agents
  2. Agent Benchmarks
  3. Observability & Debugging
  4. Reliability & Durable Execution
  5. Cost & Latency Optimization
  6. Deploying & Operating Agents

Safety & Security

Prompt injection, sandboxing, permissions, guardrails, alignment and governance for autonomous systems.

  1. Agent Security & Prompt Injection
  2. Guardrails, Permissions & Sandboxing
  3. Safety, Alignment & Governance
🔭Module 8

Advanced & Frontier

How agentic models are trained, how agents improve themselves, and the open problems that define the field's future.

  1. Training Agentic Models
  2. Self-Improving & Open-Ended Agents
  3. Open Problems & The Road Ahead
