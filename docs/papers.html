Reading list

98 papers, essays and guides that shaped the field. Start with the ⭐ essentials. Tick items off as you read them.

Cognitive Architectures for Language Agents

Sumers et al. · 2023 · Architectures & Multi-Agent

CoALA: a unifying framework describing agents by memory modules, action space and decision procedure, grounded in cognitive science.

Covered in: Single-Agent Architectures →

HuggingGPT: Solving AI Tasks with ChatGPT and its Friends in Hugging Face

An LLM controller plans tasks, selects specialist models from Hugging Face, executes them and summarizes results; an early orchestrator design.

Covered in: Single-Agent Architectures →

CAMEL: Communicative Agents for "Mind" Exploration of Large Language Model Society

Role-playing between an AI user and an AI assistant via inception prompting; an early study of autonomous agent-to-agent cooperation.

Covered in: Multi-Agent Systems →

AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation

Wu et al. · 2023 · Architectures & Multi-Agent

A framework for composing conversable agents (LLMs, tools, humans) into multi-agent conversations; influential in multi-agent tooling.

Covered in: Multi-Agent Systems →

MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework

Hong et al. · 2023 · Architectures & Multi-Agent

Encodes standard operating procedures into role-specialized agents (PM, architect, engineer) that exchange structured documents.

Covered in: Multi-Agent Systems →

ChatDev: Communicative Agents for Software Development

Qian et al. · 2023 · Architectures & Multi-Agent

A virtual software company of chatting agents following a waterfall-style process from design to testing.

Covered in: Multi-Agent Systems →

Improving Factuality and Reasoning in Language Models through Multiagent Debate

Du et al. · 2023 · Architectures & Multi-Agent

Multiple model instances propose and debate answers over rounds, improving reasoning and reducing hallucinations.

Covered in: Multi-Agent Systems →

Why Do Multi-Agent LLM Systems Fail? ⭐

MAST: a taxonomy of 14 failure modes in 3 categories (specification, inter-agent misalignment, verification) from annotated multi-agent traces; read before building one.

Covered in: Multi-Agent Systems →

SWE-bench: Can Language Models Resolve Real-World GitHub Issues? ⭐

Jimenez et al. · 2023 · Coding & Computer Use

Real issues from popular Python repositories, graded by hidden tests; became the defining benchmark for coding agents.

Covered in: Coding Agents →

Mind2Web: Towards a Generalist Agent for the Web

A large dataset of real tasks across many websites for training and evaluating generalist web agents.

Covered in: Computer-Use & Browser Agents →

SWE-agent: Agent-Computer Interfaces Enable Automated Software Engineering ⭐

OpenHands: An Open Platform for AI Software Developers as Generalist Agents
