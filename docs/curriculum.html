Syllabus

The full curriculum

40 lessons in 8 modules, ordered so each builds on the last. Total reading time ≈ 23 hours.

🧭
Module 1

Foundations

What agents are, where they came from, the LLM engine inside them, and the loop that makes them act.

  1. 1

    What Is an AI Agent?

    From Russell & Norvig's rational agent to today's LLM agents: a precise definition, the anatomy of an agent, the autonomy spectrum, and how to spot agent-washing.

    Beginner⏱ 24 min✅ 7 questions🧪 Interactive
  2. 2

    A Brief History of AI Agents

    Seventy-five years of agents, from cybernetics and Shakey the robot through BDI, reinforcement learning and ReAct to Claude Code, MCP and A2A, and what each era teaches today's builders.

    Beginner⏱ 25 min✅ 7 questions
  3. 3

    LLMs: The Engine Inside Every Agent

    Tokens, next-token prediction, transformers, context windows, training, sampling, hallucination, reasoning models and model tiers: the parts of LLMs every agent builder needs to understand.

    Beginner⏱ 28 min✅ 7 questions
  4. 4

    The Agent Loop

    The perceive–think–act cycle at the heart of every agent: transcript structure, the tool_use/tool_result cycle, stop conditions, errors as observations, and a compact working loop with the Anthropic SDK.

    Beginner⏱ 30 min✅ 7 questions🧪 Interactive
  5. 5

    Agents vs. Workflows: When (Not) to Build an Agent

    A practical decision framework: the complexity ladder from single call to agent, the math of compounding errors, cost and latency trade-offs, good and bad fits, and a checklist for deciding.

    Beginner⏱ 26 min✅ 7 questions🧪 Interactive
🧱
Module 2

Core Building Blocks

Prompts, tools, reasoning, memory, retrieval and context — the components every agent is assembled from.

  1. 6

    Prompt Engineering for Agents

    How to write system prompts that make agents act well over hundreds of steps: structure, altitude, autonomy, long-horizon state, and testing prompts like code.

    Intermediate⏱ 40 min✅ 8 questions
  2. 7

    Tool Use & Function Calling

    How LLMs call external functions: JSON Schema tool definitions, the tool_use/tool_result cycle, parallel calls, errors, strict mode, server tools and the SDK tool runner.

    Beginner⏱ 40 min✅ 7 questions🧪 Interactive
  3. 8

    Designing Great Tools (The Agent–Computer Interface)

    How to design tools agents can actually use well: descriptions as prompts, consolidated scope, high-signal responses, pagination, teaching errors, poka-yoke, safety, large tool sets, and agent-driven tool evaluation.

    Intermediate⏱ 40 min✅ 7 questions
  4. 9

    Structured Outputs & Control Flow

    Getting reliable, typed data out of LLMs: prompt-only JSON vs JSON mode vs schema-constrained decoding, Pydantic with the Anthropic SDK, validation loops, routing with enums, and LLM-decides/code-executes state machines.

    Intermediate⏱ 35 min✅ 7 questions
  5. 10

    Reasoning & Planning

    How agents think before and while they act: chain-of-thought, self-consistency, decomposition, tree search, ReAct, plan-and-execute, reflection, reasoning models and test-time compute, and where LLM planning breaks.

    Intermediate⏱ 32 min✅ 8 questions
  6. 11

    Memory Systems

    How agents remember: working vs. long-term memory, episodic, semantic and procedural stores, memory operations, MemGPT and Generative Agents, file-based memory, and the failure modes that make memory hard.

    Intermediate⏱ 32 min✅ 7 questions
  7. 12

    Retrieval & Agentic RAG

    How agents find the right information: embeddings, chunking, vector indexes, hybrid search, reranking, contextual retrieval, agentic and graph RAG, grep-style agentic search, and how to evaluate it all.

    Intermediate⏱ 34 min✅ 8 questions
  8. 13

    Context Engineering

    Curating the smallest set of high-signal tokens for every model call: the attention budget, context rot, system prompt altitude, just-in-time loading, compaction, context editing, note-taking, sub-agents and KV-cache-friendly design.

    Intermediate⏱ 34 min✅ 8 questions🧪 Interactive
🏗️
Module 3

Architectures & Patterns

Proven workflow patterns, single- and multi-agent architectures, human oversight, and the protocols that connect agents to the world.

  1. 14

    Workflow Patterns

    The six composable patterns behind most successful LLM systems: the augmented LLM, prompt chaining, routing, parallelization, orchestrator-workers and evaluator-optimizer, and when to graduate to a fully autonomous agent.

    Intermediate⏱ 35 min✅ 7 questions🧪 Interactive
  2. 15

    Single-Agent Architectures

    The design space of single agents: ReAct, MRKL, Self-Ask, Plan-and-Execute, ReWOO, LLMCompiler, Reflexion, LATS, cognitive architectures, state-machine graphs, routers and blackboards, and why one agent with good tools is the default.

    Advanced⏱ 35 min✅ 7 questions
  3. 16

    Multi-Agent Systems

    When and how to use multiple cooperating agents: topologies, communication, delegation, failure modes, the 'don't build multi-agents' debate, and a working orchestrator-subagent system.

    Advanced⏱ 35 min✅ 7 questions
  4. 17

    Human-in-the-Loop & Agent UX

    Designing oversight into agents: approval gates, interrupts and resume, clarifying questions, escalation, plans, progress, steering, undo, background agents, permission modes, and calibrated trust.

    Intermediate⏱ 30 min✅ 7 questions
  5. 18

    Protocols: MCP, A2A & Interoperability

    How agents connect to tools, data, each other and user interfaces through open standards: the Model Context Protocol, Agent2Agent, AGENTS.md, Agent Skills, AG-UI and OpenAPI-as-tools.

    Intermediate⏱ 40 min✅ 7 questions
🌍
Module 4

Agents in the Wild

How real agent categories work: coding, computer-use, deep research, conversational and voice, and embodied agents in the physical world.

  1. 19

    Coding Agents

    How AI coding agents navigate repositories, edit code, run tests and verify their own work, plus the tools, workflows, benchmarks and failure modes that matter in practice.

    Intermediate⏱ 28 min✅ 6 questions
  2. 20

    Computer-Use & Browser Agents

    How agents operate graphical interfaces through screenshots, clicks and keystrokes: perception options, browser automation, products, benchmarks, failure modes and safety.

    Intermediate⏱ 28 min✅ 6 questions
  3. 21

    Deep Research Agents

    How deep research agents plan, search, read, iterate and synthesize cited reports: architectures, multi-agent designs, STORM, source quality, citation verification and evaluation.

    Intermediate⏱ 30 min✅ 7 questions
  4. 22

    Customer-Facing & Voice Agents

    How customer-support and voice agents work: policies, tools, authentication and handoff; τ-bench evaluation; cascaded vs. speech-to-speech voice pipelines, latency, turn-taking, telephony, compliance and metrics.

    Intermediate⏱ 30 min✅ 7 questions
  5. 23

    Embodied Agents: Robots and the Physical World

    What changes when an agent's actions move atoms instead of bits: the robotics stack, LLM planners over robot skills, vision-language-action models, data, world models, evaluation, safety and open problems.

    Intermediate⏱ 32 min✅ 7 questions
  6. 24

    The Agent Landscape: Use Cases by Domain

    A domain-by-domain tour of what AI agents actually do today, why they work or don't, how mature each area is, the key risks, and a framework for spotting and measuring good agent opportunities.

    Beginner⏱ 26 min✅ 6 questions
🛠️
Module 5

Building Agents

Write an agent from scratch, learn the frameworks and SDKs professionals use, and run agents on open-weight models you host yourself.

  1. 25

    Build an Agent From Scratch

    Step by step in Python: build a real coding assistant on the Claude API, from one call to a guarded, traced, cached agent, then compare it with the SDK Tool Runner.

    Intermediate⏱ 45 min✅ 6 questions
  2. 26

    Frameworks & SDKs Compared

    A practitioner's map of the agent framework landscape in 2026: what each major framework, SDK and managed platform is for, what it costs you, and how to choose and migrate.

    Intermediate⏱ 35 min✅ 6 questions
  3. 27

    Hands-On with Agent SDKs

    Build the same repo-triage agent four ways: the Anthropic Tool Runner, the Claude Agent SDK, the OpenAI Agents SDK and LangGraph, then compare loops, tools, state, human approval and tracing.

    Advanced⏱ 50 min✅ 6 questions
  4. 28

    Agents on Open-Weight & Local Models

    Run agents on models you host yourself: why teams do it, the open-weight landscape, how tool calling really works inside chat templates, serving stacks, constrained decoding, quantization, VRAM math, hybrid designs, fine-tuning and supply-chain security.

    Intermediate⏱ 45 min✅ 7 questions
🚀
Module 6

Production Engineering

Evaluate, observe, harden, optimize and operate agents in the real world.

  1. 29

    Evaluating Agents

    How to measure whether an agent actually works: tasks, trials and graders, LLM judges and their biases, pass@k vs pass^k, error analysis, statistics, and the eval-driven development loop.

    Intermediate⏱ 45 min✅ 7 questions🧪 Interactive
  2. 30

    Agent Benchmarks

    A field guide to the benchmarks used to measure AI agents (coding, tool use, web and computer use, long-horizon work, safety), what each actually measures, and how to read leaderboards critically.

    Intermediate⏱ 40 min✅ 7 questions
  3. 31

    Observability & Debugging

    How to see what your agent actually did: traces, spans and sessions, what to capture, OpenTelemetry's GenAI conventions, a practical debugging workflow, dashboards, alerting and privacy.

    Intermediate⏱ 40 min✅ 7 questions
  4. 32

    Reliability & Durable Execution

    Make agents survive the real world: a failure taxonomy, retries with backoff and jitter, idempotent tools, circuit breakers, fallbacks, budgets, loop detection, checkpointing, durable execution and sagas.

    Advanced⏱ 38 min✅ 6 questions
  5. 33

    Cost & Latency Optimization

    Where an agent's money and seconds actually go, and how to cut both: token economics, prompt caching in depth, model routing, effort, batching, parallelism, streaming, fast mode, and measuring cost per completed task.

    Advanced⏱ 38 min✅ 7 questions🧪 Interactive
  6. 34

    Deploying & Operating Agents

    Take an agent from laptop to production: deployment shapes, sandbox infrastructure, state, secrets, multi-tenancy, rate limits, versioning, canaries, eval-gated CI/CD, monitoring, incident response, managed platforms and compliance.

    Advanced⏱ 38 min✅ 6 questions
🛡️
Module 7

Safety & Security

Prompt injection, sandboxing, permissions, guardrails, alignment and governance for autonomous systems.

  1. 35

    Agent Security & Prompt Injection

    Threat-model AI agents, understand direct and indirect prompt injection, the lethal trifecta, MCP and memory attacks, and the architectural defenses that actually hold up.

    Intermediate⏱ 35 min✅ 7 questions🧪 Interactive
  2. 36

    Guardrails, Permissions & Sandboxing

    Defense in depth for agents: input and output guardrails, permission systems and policy engines, hooks and spend caps, and sandboxes from containers to microVMs.

    Advanced⏱ 35 min✅ 6 questions
  3. 37

    Safety, Alignment & Governance

    The risks of increasingly autonomous AI: reward hacking, deception and misalignment, the research that tries to catch them, frontier safety frameworks, regulation, accountability and a responsible-deployment checklist.

    Intermediate⏱ 35 min✅ 7 questions
🔭
Module 8

Advanced & Frontier

How agentic models are trained, how agents improve themselves, and the open problems that define the field's future.

  1. 38

    Training Agentic Models

    How models learn to act: pretraining, SFT, preference optimization, RL with verifiable rewards, GRPO, teaching tool use, multi-turn agentic RL, and when to fine-tune your own agent model.

    Advanced⏱ 40 min✅ 7 questions
  2. 39

    Self-Improving & Open-Ended Agents

    How agents get better from their own experience: reflection, skill libraries, prompt and program optimization, automated agent design, self-modifying and evolutionary agents, open-endedness — and the risks and practical patterns.

    Advanced⏱ 40 min✅ 7 questions
  3. 40

    Open Problems & The Road Ahead

    Where AI agents are heading and what still blocks them: task-horizon trends, reliability, memory, evaluation, security, identity and payments, the agentic web, embodiment, work and governance — plus how to keep learning and a capstone project.

    Beginner⏱ 35 min✅ 6 questions
