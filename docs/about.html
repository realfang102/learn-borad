About Agent Academy

Agent Academy is a free, comprehensive course on AI agents: systems in which a language model directs its own process — deciding which actions to take, using tools, observing results, and iterating toward a goal.

How to use this site

  • Read in order if you're new. The curriculum is sequenced so each lesson builds on the previous ones. Or pick a learning path tailored to your goal.
  • Do the exercises. Every lesson ends with exercises, from thought experiments to coding challenges. Building is the fastest way to learn agents.
  • Take the quizzes. They're designed to check understanding and application. Explanations appear after you answer.
  • Play in the lab. Simulations make abstract mechanics — context windows, compounding errors, prompt injection — tangible.
  • Review with flashcards and test yourself with the practice exam.
  • Keyboard shortcuts: ⌘K/Ctrl K or / to search, ←/→ (with Alt) for previous/next lesson, T to toggle theme.

About the code examples

Examples are in Python unless noted. LLM calls use the Anthropic Python SDK (pip install anthropic) with current (2026) conventions; the concepts transfer directly to any provider. Framework examples follow each project's documented API at the time of writing — APIs evolve, so check the official docs when something doesn't match.

A note on a fast-moving field

Content is current as of November 2026. Model names, product features and benchmark numbers change monthly; the underlying principles — the loop, tool design, context management, evaluation discipline, least privilege — change slowly. Lessons try to teach the durable ideas and flag the perishable details.

Privacy

There is no tracking and no account. Progress, quiz scores, notes and flashcard state are stored in your browser's localStorage. Use the progress page to export or reset them.

How it's built

A small Node build script turns Markdown lessons into a static site with zero runtime dependencies (Mermaid is vendored for diagrams). Everything works offline once loaded, and the site can be hosted anywhere static files can.
